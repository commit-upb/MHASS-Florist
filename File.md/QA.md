# QA.md — Gerbang Pengiriman MHAS Florist

## Fungsional

- [ ] Tautan navbar menjangkau bagian yang nyata.
- [ ] Menu seluler berfungsi dan dapat digunakan dengan keyboard.
- [ ] Filter produk berfungsi.
- [ ] Modal detail produk terbuka/tertutup.
- [ ] Modal detail produk tertutup dengan Escape.
- [ ] Add to Cart berfungsi dari kartu dan modal.
- [ ] Penambahan/penurunan kuantitas berfungsi.
- [ ] Penghapusan item berfungsi.
- [ ] Total keranjang sudah benar.
- [ ] State keranjang kosong jelas.
- [ ] Pesan pesanan WhatsApp sudah benar.
- [ ] Lightbox galeri berfungsi.
- [ ] Akordeon FAQ berfungsi.
- [ ] Aksi peta sudah benar ketika lokasi asli disediakan.

## Responsif

- [ ] Tidak ada overflow horizontal.
- [ ] Hero mengalir ulang dengan disengaja.
- [ ] Navbar seluler dapat digunakan.
- [ ] Kartu produk mengalir ulang tanpa bertabrakan.
- [ ] Galeri ramah sentuhan.
- [ ] Keranjang muat di viewport.
- [ ] Modal muat di layar sempit.
- [ ] Tipografi tetap terbaca.
- [ ] Target interaktif kira-kira 44px atau lebih besar.

## Aksesibilitas

- [ ] Urutan Tab mengikuti urutan visual.
- [ ] Kontrol interaktif dapat dioperasikan dengan keyboard.
- [ ] Indikator fokus terlihat.
- [ ] Perilaku fokus modal sudah benar.
- [ ] State akordeon semantik.
- [ ] Gambar memiliki teks alt yang bermakna jika diperlukan.
- [ ] Teks normal menargetkan kontras 4.5:1.
- [ ] Teks besar menargetkan kontras 3:1.
- [ ] Warna bukan satu-satunya sinyal status.

## Integritas Konten

- [ ] Tidak ada statistik yang dibuat-buat.
- [ ] Tidak ada testimoni yang dibuat-buat.
- [ ] Tidak ada nama pelanggan yang dibuat-buat.
- [ ] Tidak ada alamat/rincian kontak yang dibuat-buat.
- [ ] Tidak ada klaim produk yang dibuat-buat.
- [ ] Konten yang belum dikonfirmasi memakai placeholder yang eksplisit.

## Anti-Slop

- [ ] Bagian mengikuti kebutuhan produk yang nyata.
- [ ] Tidak ada pola template landing page generik yang berulang.
- [ ] Komponen tidak semuanya berbentuk pil.
- [ ] CTA menggambarkan aksi yang nyata.
- [ ] Tidak ada kata kunci pemasaran AI.
- [ ] Palet tetap berada dalam Design.md.
- [ ] Merek tetap terasa spesifik ketika logo disembunyikan.
- [ ] Setiap pilihan visual utama memiliki alasan satu baris.
- [ ] Tidak ada elemen yang ada hanya karena template AI generik biasanya memuatnya.

## Verifikasi Build

- [ ] Build produksi berhasil.
- [ ] Konsol tidak memiliki error yang belum terselesaikan.
- [ ] Interaksi yang diubah telah diuji.
- [ ] State desktop dan seluler sudah diperiksa.

## Aturan Rilis

Jangan menandai rilis selesai selama pemeriksaan wajib masih gagal.
